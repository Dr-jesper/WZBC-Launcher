# WZBC-Launcher

**NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**

WZBC-Launcher is an independent, source-available Windows desktop launcher derived from SHOU-PCL, PCL-CE and PCL for the WZBC community. **[Dr-jesper](https://github.com/Dr-jesper) and Codex** maintain this project and are responsible for its releases and support. ## Features

Account and game-instance management, game downloads, modpacks and community-server shortcuts, with WZBC branding, campus images and light/dark WZBC, Naiwa and Naiwa Yellow themes. Updates preserve your theme selection.

## Download and use

Download the Windows x64 portable ZIP from [Releases](https://github.com/Dr-jesper/WZBC-Launcher/releases), extract it and run `WZBC-Launcher-win-x64.exe`. The .NET runtime is included; Minecraft still needs Java.

WZBC Skin, LittleSkin, MUA and offline profiles are supported. Microsoft sign-in is currently unavailable. Third-party and offline profiles do not verify Microsoft game ownership; see the [account policy](docs/wzbc/ACCOUNT-ADMISSION.md).

Version **1.2.0-wzbc.3** includes authentication error handling, account-cache isolation, launch identity checks and consistent WZBC HTTP identification. See the [release notes](docs/wzbc/RELEASE-v1.2.0-wzbc.3.md) for build and testing details.

[Community website](https://wzbcmc.cn/) · [Skin site](https://skin.wzbcmc.cn/) · [WZBC repository](https://github.com/Dr-jesper/WZBC-Launcher)

Distribution archives do not bundle Minecraft itself, modified game files, player accounts or community modpacks. Downloads are initiated by users and remain subject to the applicable providers' terms.
