## 账号与游戏 / Accounts and the game

使用 Microsoft 登录时，请使用你有权使用的个人 Microsoft 账户。用户在 Microsoft 官方网页完成授权；启动器不要求你在程序中输入 Microsoft 密码。该登录路径会检查 Minecraft 游戏权益及 Java 版玩家资料。

For Microsoft sign-in, use a personal Microsoft account you are authorized to use. Authorization takes place on Microsoft's website; the launcher does not ask for your Microsoft password. This sign-in path checks Minecraft game entitlements and the Java Edition player profile.

离线角色和皮肤站账户是独立身份，不证明你拥有 Minecraft，也不授予原本没有的游戏、服务器或其他服务访问权。请遵守 Minecraft 的适用条款，以及你选择的服务器和第三方服务的规则。

Offline profiles and skin-site accounts are separate identities. They do not establish Minecraft ownership or grant access rights you do not otherwise have. Follow the applicable Minecraft terms and the rules of the servers and third-party services you choose.

启动器不附带 Minecraft 游戏本体，也不提供 Minecraft 购买授权。购买和使用游戏请参阅 [Minecraft EULA](https://www.minecraft.net/en-us/eula) 和 [Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines)。

The launcher does not bundle Minecraft or provide a Minecraft purchase entitlement. See the [Minecraft EULA](https://www.minecraft.net/en-us/eula) and [Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines) for purchasing and using the game.

## 测试状态与支持 / Testing status and support

Microsoft 应用注册已完成，但 Minecraft Services 白名单尚未批准。目前不能将应用注册、离线自动测试或预览包视为完整真实登录与入服已验收。版本状态和已知问题以 [项目仓库](https://github.com/Dr-jesper/WZBC-Launcher) 的公开说明为准。修改游戏实例或整合包前，请备份需要保留的存档和配置。

Microsoft application registration is complete, but Minecraft Services allow-list approval has not been granted. Registration, offline automated tests and preview builds do not establish successful end-to-end real-account or server testing. Check the [project repository](https://github.com/Dr-jesper/WZBC-Launcher) for release status and known issues. Back up worlds and settings you need before changing an instance or modpack.

问题可通过项目 Issues 或联系邮箱反馈。请勿提交密码、令牌、账号配置文件或加密密钥；私密安全问题请使用邮箱。

Report problems through project Issues or the contact email. Do not submit passwords, tokens, account configuration files or encryption keys. Use email for private security reports.
