## 2026-10-24 自有 ID 实测与错误处理修复

基线 43e24c3 的本地隔离诊断构建已内置 WZBC 自有公开 Client ID，由维护者本人完成网页授权。实际 OAuth token、Xbox Live 和 XSTS 请求均为 HTTP 200；Minecraft Services `/authentication/login_with_xbox` 为 HTTP 403。权益与 Java profile 请求未到达，未验证刷新、重启恢复或游戏启动。未获取本次 403 响应正文，不将其写成已确认的封禁或具体拒审原因。

对照 SHOU-Launcher main 的 MicrosoftProvider、MojangUtils、ProfileService 和 PageLoginMs：请求端点、顺序及通用 403 的处理一致。没有通过同步来源代码改变 WZBC 的服务授权状态。

本地后续修复按 HTTP 失败阶段保留状态，区分 Xbox、XSTS、Minecraft 换票、权益和玩家资料；Minecraft 换票 403 展示服务授权状态指引，不将其误写为未购买游戏。诊断异常不包含原始响应正文或请求凭据；登录页保留原始异常调用栈。

Microsoft 刷新遇到明确协议拒绝、HTTP 400/401/403/404 或无效响应时，不允许“继续使用缓存”转为成功；invalid_grant 仍可进入重新授权。临时网络失败仅保留原有需用户确认的缓存选择，取消不能变为成功。第三方账号策略、有效缓存快速返回和全路径权益策略不在本次变更范围内。

该修复工作区完整离线回归：**378 项通过，0 失败、0 跳过**。其中 21 项新增回归覆盖真实 provider 的模拟 HTTP 阶段错误、provider 到刷新编排的拒绝传播、临时失败、失效凭据及取消。测试使用假凭据，不连接真实账号服务；它们不代表 Minecraft Services 403 已解除。
