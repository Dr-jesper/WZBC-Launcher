# 账号准入策略

更新：2026-10-31。维护者选择“模仿上游”，因此保留 SHOU-Launcher 的三类身份路径，不新增离线或皮肤站角色绑定微软账号的要求。

## 三类身份

| 身份 | 认证方式 | 适用范围 |
| --- | --- | --- |
| Microsoft | 使用 MicrosoftProvider，完整认证/刷新包括 Minecraft 游戏权益与 Java profile；同账号有效会话可按来源行为复用 | 普通实例、要求 Microsoft 的实例及社团入口 |
| Authlib / Yggdrasil Connect | 核验对应认证服务的身份和角色，不视为 Microsoft 游戏权益证明 | 普通实例、指定第三方认证实例；社团入口接受 WZBC Skin、MUA Union 和 LittleSkin |
| 离线 | 本地角色名称及 UUID，不视为在线认证或游戏权益证明 | 不要求在线认证的本地实例；保留来源购买提示、试玩逻辑；不自动进入社团服务器 |

三类身份采用同一个准入判断，不代表它们采用同一个认证服务，也不代表所有路径都完成了 Microsoft 游戏权益核验。

## 共同入口与优先级

`ModLaunch.McLaunchStart` 的预检测调用 `LaunchAccountPolicy`，不再由首页单独维护另一份账号规则。现有首页、实例页面、存档启动、服务器卡片、自定义启动事件和导出脚本的生成入口均进入这一流程。

1. 不支持或未选择的账号拒绝启动。
2. LabyMod 等要求 Microsoft 的实例优先按该要求检查。
3. 实例认证要求 1/2/3 始终检查，指定第三方服务须匹配；LabyMod 等额外 Microsoft 要求不能替代实例约束。冲突的要求拒绝启动。
4. 从服务器卡片、实例自动进服或自定义事件指向已配置社团域名时，同样应用社团规则；不依赖按钮是否设置 UseClubAccount。域名大小写、显式端口和末尾点均识别，其他域名不因含相似字符串而被认作社团域名。
5. 社团入口在实例约束通过后，继续检查受支持认证来源；两类规则须同时满足。第三方认证服务匹配协议、域名、端口和路径，兼容末尾 /authserver。

来源规则参考：SHOU-Launcher main 的 [ModLaunch.cs](https://github.com/Conduit-Club/SHOU-Launcher/blob/main/Plain%20Craft%20Launcher%202/Modules/Minecraft/ModLaunch.cs) 与 [ProfileService.cs](https://github.com/Conduit-Club/SHOU-Launcher/blob/main/PCL.Core/Minecraft/Profile/ProfileService.cs)。本轮未同步 PCL-CE 或更换来源基线。

## 缓存与账号切换

- 认证加载器每次启动都进入当前账号的认证路径，提供者仍可复用本账号未到期的会话。加载器缓存键加入稳定账号 ID，离线键还包含 UUID。
- ProfileService 缓存复用检查账号类型、稳定账号 ID、角色、认证服务和到期状态；不把另一个已保存 Microsoft 账号作为当前角色的通行证。
- Microsoft 的明确否定结果设置 authenticationInvalidated，保留账号、令牌和用户资料，但阻止后续缓存复用。此否定标记随原有加密账号存储保存并跨重启生效，成功重新认证后清除。
- 已明确被拒的会话不能因下一次出现网络故障又进入“继续使用缓存”。取消、过期和空令牌也不能变为成功。
- 重新授权返回不同的 Microsoft 角色时，拒绝覆盖原账号资料；如需使用另一个账号，应单独添加。相同 UUID 的合法改名仍兼容。
- 有效会话复用是来源兼容行为，不是本次进行了新的服务端权益检查。

## 启动中的一致性

预检测保存所选身份和目标；认证完成后核对加载器输出，再保存本次会话快照。执行自定义命令、写入启动脚本和创建游戏 Java 进程前，都会核对稳定账号、角色 UUID、认证服务、令牌摘要、到期状态、实例及目标是否仍匹配。

快照不是新的权益凭证，不向其他账号授予权限。启动进行中重复点击启动，不再覆盖活动启动的选项和快照。

脚本生成经过上述检查；按照来源保留的静态脚本在导出后由用户独立运行，启动器不能控制其后续执行。仓库没有独立的游戏 CLI 子命令，本轮未新增该功能，也不声称已验证不存在的入口。

## 验证

完整离线回归 408 项通过，0 失败、0 跳过。新用例覆盖规则优先级、来源匹配、直达社团地址、同名/跨账号会话、过期与空令牌、否定结果跨重启保留、重新授权防覆盖、启动快照及协议错误传播。

Microsoft Services 真实完整登录与游戏启动仍受当前服务端 403 阻塞；本轮不重复授权测试，不把离线/模拟结果说成真实入服成功。具体构建与人工界面结果见 [VALIDATION.md](VALIDATION.md)。
