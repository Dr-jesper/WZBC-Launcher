# WZBC 定制说明

WZBC-Launcher 使用温州商学院 Minecraft 社团品牌与授权校园素材，在 SHOU-PCL main v1.2.0 的基础上定制。

本项目由 Dr-jesper 与 Codex 共同维护，README 与启动器关于页均标注当前维护者，并保留来源项目的作者与贡献者署名。

## 品牌与主题

- 品牌紫 #601986、纸白 #F7F5F0 与深紫背景。WZBC 主题枚举为 5，新配置默认使用 WZBC。
- 奶蛙配色（6）：暖黄 #EFD858 顶栏，搭配奶油色、眼睛绿与橄榄色，提供深浅模式。
- 奶蛙黄（7）：同一暖黄顶栏，搭配中性纸白或深棕色，独立选择，提供深浅模式。
- 奶蛙参考图仅读取配色，角色图像未加入程序或仓库。标题栏、正文、悬停、选中标签和图标分别处理，避免黄底白字；切回其他主题恢复其原资源。
- 原主题索引保持兼容。更新或更换解压目录不强制覆盖用户已选主题。

标题栏、图标、启动画面、首页、关于页、中英文资源和产品名使用 WZBC；程序集名称与实例兼容路径保留。关于页保留原作者、来源社团贡献者、赞助入口和许可声明。

## 素材

Plain Craft Launcher 2/Images/Wzbc/ 收录运行所需的社团 Logo、多尺寸 ICO、启动图和四张校园轮播。品牌图由社团提供，校园图来自社团官网复建素材；仅缩放与格式转换，未重绘 Logo。校园图最高 1920×1080，保留比例，来源及产物校验值见 [ASSETS.json](ASSETS.json)。原始参考图与重复横幅不随源码发布。
